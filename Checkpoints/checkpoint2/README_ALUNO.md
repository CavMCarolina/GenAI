# Checkpoint - Contexto Longo

## Preparacao
1. Extraia todo o ZIP, preservando a pasta `dados`.
2. Abra `atividade.ipynb` no VS Code ou Jupyter.
3. Instale as dependencias de `requirements.txt`.
4. Crie a variavel de ambiente `OPENROUTER_API_KEY` com sua propria chave.
5. Execute o notebook na ordem.

## Arquivos
- `atividade.ipynb`: roteiro e codigo inicial.
- `dados/dossie_aurora.txt`: cenario sintetico principal com 260 documentos.
- `dados/longbench_hotpotqa_exemplo.json`: extensao real do LongBench/Hugging Face.
- `TAREFA_TEAMS.md`: enunciado e rubrica.
- `.env.example`: nome da variavel esperada; nao coloque sua chave neste arquivo para entrega.

## Atividade obrigatoria
Toda a atividade esta em `atividade.ipynb`. Execute na ordem e complete os quatro blocos `TODO`:
1. implementar a reducao;
2. consultar e validar o LLM;
3. aplicar a mesma estrategia ao LongBench;
4. escrever a conclusao comparativa.

Entregue somente o notebook executado. Os cenarios Aurora e LongBench sao obrigatorios.
